# Task Tracker API

Добро пожаловать в Task Tracker API! Этот API позволяет управлять задачами, статусами, комментариями и аутентификацией пользователей. Ниже вы найдете подробную информацию о доступных эндпоинтах и их использовании.

## Запуск через docker-compose

Клонируйте репозиторий:

```shell
git clone https://github.com/xfn3t/task_manager
```

Перейдите в директорию проекта:

```shell
cd target_manager
```

Запустите через docker-compose:

```shell
docker-compose up --build
```

## Базовые эндпоинты

Документация Swagger будет доступна после запуска проекта:

http://localhost:8080/swagger-ui/index.html

## Задачи

### Получить задачи

**Эндпоинт:** `GET /api/tasks`

**Описание:** Возвращает список задач текущего пользователя или все задачи для администратора. Фильтрация по параметру `visible` учитывает настройку видимости задачи для других пользователей.

**Параметры:**
- `visible` (опционально): Фильтр по видимости задачи.

**Ответы:**
- `200 OK`: Список задач успешно получен.
- `404 Not Found`: Задачи не найдены.

### Получить задачу по ID

**Эндпоинт:** `GET /api/tasks/{taskId}`

**Описание:** Возвращает задачу по ID, если она принадлежит текущему пользователю.

**Параметры:**
- `taskId` (path): ID задачи.

**Ответы:**
- `200 OK`: Задача успешно получена.
- `404 Not Found`: Задача не найдена.

### Создать задачу

**Эндпоинт:** `POST /api/tasks`

**Описание:** Создает новую задачу для текущего пользователя. Параметр `visibility` определяет видимость задачи для других пользователей.

**Тело запроса:**
```json
{
  "title": "Новая задача",
  "description": "Описание задачи",
  "visibility": true,  // Видимость для других пользователей
  "statusId": 1,
  "priorityId": 2,
  "userId": 3,
  "executorsIds": [3, 4],
  "commentsIds": []
}
```

**Ответы:**
- `200 OK`: Задача успешно создана.
- `400 Bad Request`: Ошибка при создании задачи.

### Обновить задачу

**Эндпоинт:** `PUT /api/tasks/{taskId}`

**Описание:** Обновляет существующую задачу, принадлежащую текущему пользователю.

**Параметры:**
- `taskId` (path): ID задачи.

**Тело запроса:**
```json
{
  "title": "Обновленная задача",
  "description": "Новое описание",
  "visibility": false,  // Видимость для других пользователей
  "statusId": 2,
  "priorityId": 1,
  "userId": 3,
  "executorsIds": [4, 5],
  "commentsIds": [1, 2]
}
```

**Ответы:**
- `200 OK`: Задача успешно обновлена.
- `400 Bad Request`: Ошибка обновления.

### Удалить задачу

**Эндпоинт:** `DELETE /api/tasks/{taskId}`

**Описание:** Удаляет задачу по ID, если она принадлежит текущему пользователю.

**Параметры:**
- `taskId` (path): ID задачи.

**Ответы:**
- `204 No Content`: Задача успешно удалена.
- `400 Bad Request`: Ошибка удаления.

### Изменить статус задачи

**Эндпоинт:** `PATCH /api/tasks/{taskId}/status`

**Описание:** Обновляет статус задачи, если пользователь имеет доступ.

**Параметры:**
- `taskId` (path): ID задачи.

**Тело запроса:**
```json
{
  "id": 2
}
```

**Ответы:**
- `200 OK`: Статус успешно обновлен.
- `400 Bad Request`: Ошибка обновления статуса.

## Статусы

### Получить все статусы

**Эндпоинт:** `GET /api/status`

**Описание:** Возвращает список всех статусов. Параметр `isGlobal` в статусе определяет, является ли статус глобальным (видимым для всех) или локальным (только для владельца).

**Ответы:**
- `200 OK`: Список статусов получен.
- `404 Not Found`: Статусы не найдены.

### Получить статус по ID

**Эндпоинт:** `GET /api/status/{statusId}`

**Описание:** Возвращает статус по ID.

**Параметры:**
- `statusId` (path): ID статуса.

**Ответы:**
- `200 OK`: Статус получен.
- `404 Not Found`: Статус не найден.

### Добавить статус

**Эндпоинт:** `POST /api/status`

**Описание:** Создает новый статус. Параметр `isGlobal` определяет глобальную видимость статуса.

**Тело запроса:**
```json
{
  "title": "Новый статус",
  "isGlobal": false,  // false = локальный статус (только для пользователя)
  "userId": 1
}
```

**Ответы:**
- `200 OK`: Статус создан.
- `400 Bad Request`: Неверные данные.

### Обновить статус

**Эндпоинт:** `PUT /api/status/{statusId}`

**Описание:** Обновляет существующий статус.

**Параметры:**
- `statusId` (path): ID статуса.

**Тело запроса:**
```json
{
  "title": "Обновленный статус",
  "isGlobal": true,  // true = глобальная видимость
  "userId": null
}
```

**Ответы:**
- `200 OK`: Статус обновлен.
- `400 Bad Request`: Неверные данные.
- `404 Not Found`: Статус не найден.

### Удалить статус

**Эндпоинт:** `DELETE /api/status/{statusId}`

**Описание:** Удаляет статус по ID.

**Параметры:**
- `statusId` (path): ID статуса.

**Ответы:**
- `204 No Content`: Статус удален.
- `404 Not Found`: Статус не найден.

## Комментарии

### Получить все комментарии

**Эндпоинт:** `GET /api/comments`

**Описание:** Возвращает все комментарии текущего пользователя.

**Ответы:**
- `200 OK`: Комментарии получены.

### Получить комментарии задачи

**Эндпоинт:** `GET /api/comments/{taskId}`

**Описание:** Возвращает комментарии конкретной задачи, если пользователь имеет доступ.

**Параметры:**
- `taskId` (path): ID задачи.

**Ответы:**
- `200 OK`: Комментарии получены.
- `404 Not Found`: Комментарии не найдены.

### Добавить комментарий

**Эндпоинт:** `POST /api/comments/{taskId}`

**Описание:** Добавляет комментарий к задаче.

**Параметры:**
- `taskId` (path): ID задачи.

**Тело запроса:**
```json
{
  "content": "Новый комментарий"
}
```

**Ответы:**
- `200 OK`: Комментарий добавлен.
- `400 Bad Request`: Ошибка добавления.

### Ответ на комментарий

**Эндпоинт:** `POST /api/comments/{taskId}/{parentCommentId}/reply`

**Описание:** Добавляет ответ к комментарию.

**Параметры:**
- `taskId` (path): ID задачи.
- `parentCommentId` (path): ID родительского комментария.

**Тело запроса:**
```json
{
  "content": "Ответ на комментарий"
}
```

**Ответы:**
- `200 OK`: Ответ добавлен.
- `400 Bad Request`: Ошибка добавления.

## Аутентификация

### Вход

**Эндпоинт:** `POST /auth/login`

**Описание:** Аутентификация пользователя.

**Тело запроса:**
```json
{
  "username": "пользователь",
  "password": "пароль"
}
```

**Ответы:**
- `200 OK`: Успешная аутентификация.
- `401 Unauthorized`: Неверные данные.
- `500 Internal Server Error`: Ошибка сервера.

### Регистрация

**Эндпоинт:** `POST /auth/signup`

**Описание:** Регистрация нового пользователя.

**Тело запроса:**
```json
{
  "username": "новый_пользователь",
  "password": "новый_пароль",
  "email": "user@example.com"
}
```

**Ответы:**
- `200 OK`: Успешная регистрация.
- `400 Bad Request`: Неверные данные.
- `500 Internal Server Error`: Ошибка сервера.
```
